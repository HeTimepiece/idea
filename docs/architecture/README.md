# Web3/X Matrix Architecture v1

## Purpose

This directory is the source of truth for the first-phase technical architecture of the Web3 hot-topic collection, AI content production, compliance review, and X multi-account publishing system.

## Files

- `system-architecture.md`: implementation-ready architecture spec
- `architecture-summary.json`: structured decisions for downstream agents

## Scope

This architecture targets phase 1 delivery:

1. Collect hot topics from selected Web3 sources
2. Generate candidate posts with AI
3. Rewrite to reduce generic AI tone
4. Review for policy, factual, and brand risks
5. Publish to X through isolated account workspaces
6. Operate multiple accounts from one control plane
